# Data sources

| File | Contains | Source | Licence | Accuracy note |
|---|---|---|---|---|
| `sample-data/villages.json` | 14 villages: id, name, district, coordinates, river distance, slope class, illustrative population | Prepared by the team for the prototype | Project licence (MIT) | Coordinates and river distances are approximate; population is an illustrative estimate, not a census figure |
| `sample-data/risk_points.json` | South Lhonak glacial lake (approximate location), 4 simulated river gauges, 3 illustrative landslide zones | Prepared by the team for the prototype | Project licence (MIT) | Gauge current/danger/normal levels are simulated — there is no live public feed in this prototype |
| `sample-data/shelters.json` | 21 sample shelters (schools, community halls, monasteries) near each village | Prepared by the team for the prototype | Project licence (MIT) | Not verified real facilities — names, locations and capacities are illustrative |
| `sample-data/rainfall_fallback.json` | Synthetic 72-hour rainfall (mm/hour) per village, seeded random generation | Generated by the team for offline demos | Project licence (MIT) | Synthetic data; used whenever live weather is unavailable or `WEATHER_MODE=offline` |
| Live rainfall | 72-hour precipitation forecast, batched per-village request | [Open-Meteo](https://open-meteo.com/) | CC BY 4.0 — attribution required | Real forecast data, used only when `WEATHER_MODE=live` and the API is reachable |
| Map tiles | Base map tiles | [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) | ODbL | Standard OSM tile usage with required attribution |

Before any real use, replace sample data with verified data from the Sikkim State Disaster Management Authority and district administrations.
